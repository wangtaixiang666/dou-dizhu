# 本地小游戏合集（斗地主 / 2048）

两个**完全离线、单文件**的网页小游戏，双击 HTML 就能玩，不联网、不上传任何数据。

- **斗地主**：一个人打两个电脑，内置训练过的出牌模型；有场次、金币、账号、签到、商城、Q 版人物与语音。
- **2048**：石块与翻倍主题的 2048 变体。

## 在线试玩

仓库开启 GitHub Pages 后，直接访问站点首页即可（自动跳转到斗地主）。

## 本地运行

直接双击 `斗地主.html` 或 `2048-stones.html`，用浏览器打开即可。

> 建议用 `file://` 方式打开（桌面双击）。如果在某些预览面板/沙箱里打开，浏览器会因 `sandbox` 限制或端口变化导致 `localStorage` 不可用，账号可能读不到——游戏顶部会给出提示，并支持 **备份码 / 备份文件** 恢复账号。

## 玩法要点

| 模块 | 说明 |
|---|---|
| 场次 | 新手场 / 进阶场 / 大师场，底分与准入金币不同 |
| 账号 | 本地账号（ID + 密码），数据全在浏览器 `localStorage`，可导出 `DDZ1-...` 备份码 |
| 商城 | 皮肤、衣服、饰品、道具（翻倍卡 / 护身符 / 幸运符） |
| 人物 | 可改性别体型的 Q 版立绘，按心情切换 idle / 思考 / 得意 / 沮丧 / 出牌等动作 |
| 语音 | 出牌、抢地主、剩牌告急等场景有台词 + 合成音效（WebAudio / speechSynthesis，无需联网） |
| 提示 | 对手剩牌 ≤ 2 时人物会得意喊话，牌数角标变橙脉冲 |

## 目录结构

```
斗地主.html          # 构建产物：单文件游戏（引擎/模型/权重全部内联）
2048-stones.html     # 2048 小游戏
ddz/
  ui.html            # 界面 + 交互源码（CSS/JS 唯一来源）
  engine.js          # 斗地主规则引擎（牌型识别、比较、合法出牌）
  bot-heuristic.js   # 启发式机器人
  model.js           # 出牌策略网络（前向推理）
  weights-best.json  # 训练得到的权重
  match.js           # 对局编排
  build.js           # 把上面几块内联进 ui.html，产出 斗地主.html
  test-engine.js     # 规则引擎回归测试
  train.js           # 模型训练脚本
  eval.js            # 模型评估
  paired-eval.js     # 对照评测（新权重 vs 旧权重）
```

## 构建

```bash
node ddz/build.js        # 重新生成 斗地主.html
node ddz/test-engine.js  # 规则引擎回归测试
```

改界面只改 `ddz/ui.html`，然后跑一次 `build.js` 即可；不要直接编辑 `斗地主.html`，它在构建时会被整体覆盖。

## 说明

纯前端实现，无后端、无依赖、无外部请求。所有进度（账号、金币、道具）只保存在你自己的浏览器里，换浏览器或清缓存前请先导出备份码。
